# 俄罗斯方块

用 Pygame 写的俄罗斯方块。棋盘为 10×20，包含七种方块、下一个方块预览、消行计分和随等级加快的下落速度。

## 运行

需要 Python 3.9 或更高版本。

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python tetris.py
```

## 操作

| 按键 | 作用 |
| --- | --- |
| ← → | 左右移动 |
| ↑ 或 X | 旋转 |
| ↓ | 加速下落 |
| 空格 | 直接落到底 |
| P | 暂停 / 继续 |
| R | 重新开始 |
| Q 或 Esc | 退出 |

## 规则

- 消掉 1、2、3、4 行分别得 100、300、500、800 分，再乘以当前等级。
- 每消除 10 行升 1 级，方块下落更快。
- 新方块出现时如果已经没有空位，游戏结束。按 R 可以重开。
